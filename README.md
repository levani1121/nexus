# Nexus - თანამედროვე & ადაპტური Landing Page

სუფთა **Vanilla HTML5**, **CSS3** და **JavaScript** ტექნოლოგიებით შექმნილი თანამედროვე, სწრაფი და სრულად ადაპტური (Responsive) სადესანტო გვერდი.

---

## 🚀 პროექტის სტრუქტურა

```
myfirstproject/
├── index.html        # სემანტიკური HTML5 სტრუქტურა (Hero, About, Features, Contact, Footer)
├── style.css         # თანამედროვე დიზაინ სისტემა, Glassmorphism, ანიმაციები და მობილური ადაპტაცია
├── script.js         # ჰამბურგერ მენიუ, სმუზ სქროლი, IntersectionObserver და ფორმის ვალიდაცია
└── README.md         # პროექტის დოკუმენტაცია
```

---

## 📌 ძირითადი სექციები

1. **Header & Navigation (ნავიგაცია)**:
   - ფიქსირებული / Sticky ჰედერი Glassmorphism (Backdrop Blur) ეფექტით.
   - აქტიური სექციის ავტომატური გამოკვეთა სქროლვისას (`IntersectionObserver`).
   - გლუვი გადასვლა (`smooth scroll`) შესაბამის სექციებზე.
   - მობილური ჰამბურგერ მენიუ ანიმაციით (X-ტრანსფორმაცია) და სრული ადაპტაციით.

2. **1. Hero სექცია (მთავარი)**:
   - მთავარი თვალშისაცემი სათაური გრადიენტული ტექსტით.
   - ქვესათაური და პირველადი (CTA) / მეორადი ღილაკები.
   - რეალური ინტერაქტიული ვიზუალი — ანალიტიკის ბარათი, დინამიური სვეტები და მცურავი ბეიჯები (`Floating Badges`).
   - ნდობის ინდიკატორები (99.9% საიმედოობა, 50k+ მომხმარებელი).

3. **2. About სექცია (ჩვენ შესახებ)**:
   - პროდუქტის/სერვისის დეტალური და მიმზიდველი ტექსტური აღწერა.
   - უპირატესობების სია მორგებული SVG ჩექმარკებით.
   - 3 სტატისტიკური ბარათი ინდივიდუალური ინდიკატორებით.

4. **3. Features სექცია (შესაძლებლობები)**:
   - **ზუსტად 3 ბარათი** თანამედროვე SVG იკონკებით:
     - ⚡ **სწრაფი წარმადობა**
     - 🛡️ **უმაღლესი უსაფრთხოება**
     - 📈 **ანალიტიკა და ზრდა**
   - თანამედროვე **Hover ეფექტი**: ბარათის აწევა (`translateY(-8px)`), კურსორის თანმხლები ნათება, იკონის როტაცია და გრადიენტული ჩარჩო.

5. **4. Contact სექცია (კონტაქტი)**:
   - საკონტაქტო ინფორმაცია (ელ-ფოსტა, ტელეფონი, მისამართი და სოციალური ქსელები).
   - **საკონტაქტო ფორმა JS ვალიდაციით**:
     - **სახელი**: ცარიელი ველის შემოწმება და მინიმუმ 2 სიმბოლო.
     - **Email**: ფორმატის შემოწმება რეგულარული გამოსახულებით (`Regex`).
     - **შეტყობინება**: ცარიელი ველის შემოწმება და მინიმუმ 10 სიმბოლო.
     - რეალურ დროში შეცდომის გასუფთავება ტექსტის აკრეფისას.
     - ღილაკის Loading სპინერი და ანიმირებული წარმატების შეტყობინება (`Success alert`).

6. **Footer & Back to Top**:
   - თანამედროვე ფუტერი საავტორო უფლებებითა და ნავიგაციით.
   - "Back to top" ღილაკი, რომელიც ჩნდება 350px-ზე მეტი ჩამოსქროლვისას.

